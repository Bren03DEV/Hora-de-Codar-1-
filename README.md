# 📐 Resolução de Exercícios: Cálculo de Áreas (JavaScript)

Este repositório contém a resolução de uma lista de exercícios de **Lógica de Programação** focada no cálculo de áreas de figuras planas utilizando **JavaScript**.

## 📝 Descrição do Projeto

O objetivo principal foi criar scripts que interagem com o usuário para calcular a área de diferentes formas geométricas, aplicando conceitos fundamentais da linguagem.

## 🧠 Conceitos Aplicados

- **Entrada de dados:** Uso de `prompt()` para receber valores.
- **Tratamento de dados:** Conversão de strings para números decimais com `parseFloat()`.
- **Estruturas de Controle:** Organização das opções de cálculo através de `switch/case`.
- **Variáveis:** Utilização de `const` e `let` para manipulação de dados na memória.
- **Matemática no JS:** Uso do objeto `Math` (`Math.PI`, `Math.pow()`).

## 🚀 Formas Geométricas Incluídas

- Triângulo — `A = (b × h) / 2`
- Quadrado — `A = L²`
- Círculo — `A = π × r²`

## 🛠️ Como Rodar o Projeto

Como o código utiliza comandos do navegador (`prompt` e `console`), você pode:

1. Copiar o código de qualquer exercício.
2. Abrir o **Console do Desenvolvedor** no navegador (`F12` ou `Ctrl + Shift + I`).
3. Colar o código no console.
4. Pressionar **Enter** para executar.
